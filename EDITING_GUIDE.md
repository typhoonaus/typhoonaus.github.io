# Editing the Typhoon Website

Use a plain-text code editor for these files, such as Visual Studio Code, Sublime Text, Atom, or TextEdit in plain-text mode.

Do not save `index.html` as Rich Text, RTF, or RTFD. If TextEdit asks to change the format, choose plain text instead.

Most content is edited in `app.js`, not `index.html`.

Edit these sections in `app.js`:

- Team members: `teamMembers`
- GoFundMe numbers: `goFundMeCampaign`
- Sponsor tiers and logos: `sponsors`
- Competition history: `timelineItems`
- Page text: `renderHome`, `renderAbout`, `renderJourney`, and `renderPartners`

Keep commas between items in lists. If the page goes blank after an edit, the most common cause is a missing quote, comma, bracket, or parenthesis.

The `index.html` file should usually only be changed for things like the page title, Google tag, favicon, navigation, or footer shell.
